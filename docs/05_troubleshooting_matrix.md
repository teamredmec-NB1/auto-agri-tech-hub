# เมทริกซ์การวิเคราะห์ปัญหาและอาการเสีย 30 อาการหลัก

ดูรายละเอียดเต็มในไฟล์ `diesel_engine_master_encyclopedia.xlsx` แผ่นงานที่ 6

### สรุปอาการวิกฤต:
1. **ควันดำหนาแน่น:** ตรวจสอบกรองอากาศตัน, ท่ออินเตอร์คูลเลอร์แตก, หัวฉีดฉีดหยด
2. **ควันขาวกลิ่นหวาน:** ปะเก็นฝาสูบแตก น้ำหล่อเย็นรั่วเข้าห้องเผาไหม้
3. **ควันขาวกลิ่นดีเซลฉุน:** หัวเผาขาด, กำลังอัดต่ำ, มีน้ำปนในดีเซล
4. **ควันฟ้าอมขาว:** แหวนลูกสูบหัก, ยางหมวกวาล์วเสื่อม, ซีลแกนเทอร์โบรั่ว
5. **น้ำมันเครื่องสีกาแฟใส่นม:** ออยล์คูลเลอร์แตกทะลุ ห้ามสตาร์ทเครื่องเด็ดขาด
6. **เสียงเคาะตึ้กๆ ใต้ท้องเครื่อง:** ชาร์ปอกหรือชาร์ปก้านละลาย ดับเครื่องทันที
7. **รอบเครื่องเร่งค้างคุมไม่อยู่ (Runaway):** น้ำมันเครื่องรั่วเข้าไอดี หาทางอุดปิดปากท่อไอดีเพื่อตัดอากาศทันที
